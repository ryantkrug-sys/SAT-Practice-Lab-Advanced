SAT Practice Lab

Open index.html in a modern desktop browser to launch the local practice lab.

Available assessments:
Mathematics
- Algebra
- Advanced Math
- Problem-Solving and Data Analysis
- Geometry and Trigonometry

Reading & Writing
- Information and Ideas
- Craft and Structure
- Expression of Ideas
- Standard English Conventions

Reading & Writing assessments use the question banks provided by the user. Questions, answer choices, correct answers, and explanations are retained from the supplied PDFs. Internal source metadata such as question IDs and assessment labels is not displayed in the active test. The active test displays the question and answer choices; the correct answer and explanation appear in the results report.

Each assessment has 30 questions, adaptive difficulty, no backward navigation, and a maximum displayed score of 89. Hard questions are worth 1 point, Very Hard questions 2 points, and Expert questions 3 points. Reading & Writing questions were tiered comparatively within each domain using a difficulty-ranking heuristic based on question structure, language/reasoning cues, answer-choice complexity, and explanation length. In Expression of Ideas, PSAT-source questions received a modest downward adjustment in the ranking when compared with SAT-source questions.

The Reading & Writing Return to Main Screen buttons ask for confirmation before leaving an assessment. The four existing Mathematics assessment files have been preserved unchanged from the supplied baseline ZIP; the main menu was updated to enable the four Reading & Writing assessments.

To use the project, extract the ZIP completely before opening index.html. Do not open individual assessment files from inside the ZIP preview. No installation is required.
